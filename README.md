# Perfume Consumer Preferences - Agent-Based Model

This repository contains the Python implementation developed for my Final Year Project, **"Simulating Consumer Preferences for Perfume Using Agent-Based Modelling in Python."**

## Project Overview

The project uses Agent-Based Modelling (ABM) to simulate consumer perfume choices within a simplified perfume market. Consumer agents differ in their scent preferences, price sensitivity and susceptibility to social influence.

The simulation investigates how these individual characteristics can contribute to wider popularity patterns across multiple simulation rounds.

## Features

- 100 simulated consumer agents
- Five perfume products
- 50 simulation rounds
- Scent preference matching
- Price sensitivity
- Social influence based on perfume popularity
- Weighted consumer choices
- Low, baseline and high social influence scenarios
- Low, baseline and high price sensitivity scenarios
- Results displayed using Pandas and Matplotlib

## Technologies

- Python
- Jupyter Notebook
- Pandas
- Matplotlib

## Running the Project

Open `perfume_consumer_abm.ipynb` in Jupyter Notebook and run the cells in order from top to bottom.
